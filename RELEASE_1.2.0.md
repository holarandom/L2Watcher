# L2 Watcher 1.2.0

Небольшое дополнение к 1.1.0 — то, что всплыло уже после её публикации.
Если 1.1.0 у тебя работает нормально, обновление не срочное.

## 🆕 Об обновлении сообщает само приложение

Раньше про новую версию писал только Telegram-бот. Если Telegram недоступен
(блокировки, отвалившийся VPN) — человек про обновление не узнавал вообще.

Теперь при выходе новой версии:

- в меню трея сверху появляется пункт **«🆕 Скачать версию X»** — по клику
  открывается страница загрузки;
- всплывает окошко Windows — один раз за запуск, а не каждые сутки;
- у иконки в трее меняется подсказка.

Telegram по-прежнему тоже пишет — он просто больше не единственный источник.

> ⚠️ **Заработает со следующего обновления.** Пункт в трее рисует та версия,
> которая у тебя уже запущена, — а в 1.1.0 этой возможности ещё нет. Поэтому
> про выход самой 1.2.0 старые версии сообщают по-прежнему только через
> Telegram. Зато о 1.3.0 и дальше приложение скажет уже само, даже если
> Telegram недоступен.

## 🔐 У .exe появились свойства файла

Раньше в свойствах файла было пусто: ни издателя, ни названия, ни версии.
Теперь там указано, что это за программа, какой версии и чья:

```
Издатель:  holarandom
Продукт:   L2 Watcher
Версия:    1.2.0.0
Копирайт:  Copyright (c) 2026 holarandom. MIT License.
```

Видно в свойствах файла и в Диспетчере задач. Заодно это убирает один из
поводов для антивирусов считать файл подозрительным: безымянный .exe без
издателя автоматика оценивает строже.

## ⚙️ Автозагрузка переехала с реестра на ярлык

**Для тебя ничего не меняется** — та же галочка в настройках, тот же
результат. Меняется то, как это устроено внутри.

Раньше путь к программе прописывался в ключ реестра `Run`. Работало
нормально, но запись в этот ключ — классический признак «программа
закрепляется в системе», и антивирусы ищут его в первую очередь: Windows
Defender прямо назвал наш ключ среди причин, по которым пометил сборку как
угрозу.

Теперь создаётся обычный ярлык в папке «Автозагрузка» — так поступают все
нормальные установщики.

**Если автозапуск был включён — он переедет сам** при первом запуске новой
версии. Делать ничего не нужно. Если ярлык вдруг не создастся, старая запись
в реестре останется на месте, чтобы автозапуск не пропал.

## Обновление

Скачай архив и распакуй **поверх старой папки**. Настройки и обученные
шаблоны не тронутся — они лежат в `%APPDATA%\L2Monitor\`, переобучать ничего
не нужно.

## Проверка файла

Программа собрана без цифровой подписи — сертификат стоит от 100 $ в год и
для бесплатного проекта не окупается. Проверить подлинность можно так:

**SHA256 архива:**

```
FA8165EDB3E6AD401D7BADDD8900345C71C4D1F00A58C7E4ADF3EEB07B3CF8DE
```

Сверить у себя (PowerShell):

```powershell
Get-FileHash L2Watcher_v1.2.0.zip -Algorithm SHA256
```

**Отчёт VirusTotal:** https://www.virustotal.com/gui/file/fa8165edb3e6ad401d7baddd8900345c71c4d1f00a58c7e4adf3eeb07b3cf8de?nocache=1

Отдельные антивирусы могут пометить файл как подозрительный обезличенным
именем вида `Trojan:Win32/Wacatac` — это ложное срабатывание. Программа
собрана упаковщиком PyInstaller, который распаковывает код в память при
запуске; так же устроены и вредоносные упаковщики, и автоматика их не
различает. Подробнее и что с этим делать — в разделе README «Антивирус
ругается на .exe». Исходный код открыт целиком, можно собрать самому.
